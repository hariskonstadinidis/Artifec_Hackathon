# Artifec × Codam Hackathon (16–19 Oct 2026)

**Challenge:** make the receipt problem disappear for businesses. Every client lunch, taxi ride or parking ticket leaves a small paper receipt that someone has to collect, scan, book and keep for years.

Final presentation to Artifec's CEO and CTO: Monday 19 Oct, 15:00.

## Repo layout
- `docs/raw/artifec-hackathon-brief.txt`: the original hackathon brief
- `docs/research/sources.md`: all **verified** sources with IDs (`[S#]`, `[P#]`) plus a list of removed/unreliable claims
- `docs/research/dutch-market.md`: Dutch market analysis: size, bottlenecks in the receipt journey, regulation, competitors
- `docs/research/competitors.md`: 💣 minesweeper map of 15+ competitors (what already exists, where the gap is)
- `docs/research/brainstorm-transaction-evidence.md`: broad brainstorm (missing / untrusted / disconnected proof, adjacent markets, problem owners), with verification marks
- `docs/research/key-facts.md`: presentation-ready data points, the draft story and open questions
- `docs/pitch/playbook.md`: pitch & demo best practices for this event, plus likely Q&A questions
- `docs/pitch/mvp.md`: MVP principles, our scope (TBD), timeline and decision log
- `docs/pitch/presentation.md`: living slide-by-slide outline
- `docs/pitch/pitch-script.md`: spoken script with timings and Q&A answers

> The pitch files are **living documents**: update them whenever the MVP, data or decisions change.
